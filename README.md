# 🛠️ OS Management Tool

This Python script helps with basic system management tasks:

- 📂 Automatically organizes files (images, videos, PDFs) into folders
- 📊 Monitors system usage: CPU, RAM, Disk
- 🔁 Automatically creates backups of organized files
- 📝 Logs memory usage to a file

---

## ⚙️ Requirements

- Python 3.x
- psutil

Install dependencies:

```bash
pip install psutil
